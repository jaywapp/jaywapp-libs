# Jaywapp.Algorithm.KMP

KMP(Knuth-Morris-Pratt) 문자열 매칭 알고리즘 구현 및 교육용 CLI 도구.

## 기술 스택

| | |
|--|--|
| 언어 / 플랫폼 | C# / .NET Framework 4.7.2 |
| 의존 | Jaywapp.Algorithm |

## 기능

대화형 CLI를 통해 문자열 검색 알고리즘을 실행·비교할 수 있습니다.

| 메뉴 | 설명 |
|------|------|
| Brute Force | 단순 완전 탐색 |
| KMP | KMP 알고리즘 실행 |
| Prefix 분석 | 실패 함수(failure function) 시각화 |
| 성능 비교 | Brute Force vs KMP 처리 시간 비교 |

## 실행

```bash
dotnet run
```
