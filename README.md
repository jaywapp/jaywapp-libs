# jaywapp-libs

Jaywapp C# 라이브러리 모노레포. 기존에 개별 레포로 분리되어 있던 라이브러리들을 하나로 통합했습니다.

## 라이브러리 목록

| 라이브러리 | 설명 |
|-----------|------|
| [Jaywapp.Algorithm](src/Jaywapp.Algorithm) | 알고리즘 유틸리티 |
| [Jaywapp.Algorithm.KMP](src/Jaywapp.Algorithm.KMP) | KMP 문자열 검색 알고리즘 |
| [Jaywapp.API](src/Jaywapp.API) | API 공통 인터페이스 |
| [Jaywapp.AppendableFilter](src/Jaywapp.AppendableFilter) | 확장 가능한 필터 컴포넌트 |
| [Jaywapp.Graphic.Geometry](src/Jaywapp.Graphic.Geometry) | 그래픽 지오메트리 유틸리티 |
| [Jaywapp.Infrastructure](src/Jaywapp.Infrastructure) | 공통 인프라 레이어 |
| [Jaywapp.Slack](src/Jaywapp.Slack) | Slack 연동 |
| [Jaywapp.Test.PropertyTools.TreeListBox](src/Jaywapp.Test.PropertyTools.TreeListBox) | TreeListBox 프로퍼티 테스트 도구 |
| [Jaywapp.Toasket](src/Jaywapp.Toasket) | Toast 알림 컴포넌트 |
| [Jaywapp.UI](src/Jaywapp.UI) | 공통 UI 컴포넌트 |
| [Jaywapp.Utility.BuilderWizard](src/Jaywapp.Utility.BuilderWizard) | 빌더 위저드 유틸리티 |
| [Jaywapp.Wpf](src/Jaywapp.Wpf) | WPF 공통 컴포넌트 |
